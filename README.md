# GitHub Copilot CLI - Curso de Pruebas

Repositorio de práctica para el curso de **GitHub Copilot CLI**.

## Descripción

Este repositorio contiene ejemplos, ejercicios y experimentos realizados durante el aprendizaje del uso de GitHub Copilot CLI.

## Tecnologías utilizadas

- JavaScript
- PHP
- HTML
- CSS

## Requisitos previos

- [Git](https://git-scm.com/)
- [GitHub CLI](https://cli.github.com/)
- [Node.js](https://nodejs.org/) (opcional)

## Instalación

```bash
git clone https://github.com/tu-usuario/github-cli.git
cd github-cli
```

## Uso

Este repositorio es exclusivamente para fines educativos y de práctica del curso de GitHub Copilot CLI.
